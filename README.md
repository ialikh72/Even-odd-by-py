# Even and Odd Number Checker (Python)

## Description
This is a simple Python program that checks whether a number entered by the user is **even** or **odd**.  
The program takes an integer input from the user and uses the **modulus operator (%)** to determine if the number is divisible by 2.

If the number is divisible by 2, it is **even**. Otherwise, it is **odd**.

---

## How the Program Works
1. The program asks the user to enter a number.
2. The number is stored in a variable.
3. The program checks the remainder when the number is divided by 2.
4. If the remainder is **0**, the number is even.
5. If the remainder is **not 0**, the number is odd.
6. The result is displayed on the screen.
